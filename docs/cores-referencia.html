Sistema de cores do workhub

Paleta laranja sobre neutros quentes no claro e cinza neutro no escuro. Toda cor é uma CSS custom property — clique em qualquer valor para copiar e reaproveite o mesmo padrão em outros projetos.

Regra de ouro: componente nunca usa hex cru, sempre var(--token). Trocar de tema ou de marca = editar só os blocos :root / body.dark.
Fonte da verdade no código: frontend/src/index.css (blocos :root e body.dark). Fonte do produto: Open Sans.
